# crew/

Agent definitions by **role** — planner, implementer, reviewer, tester, debugger, researcher, sysadmin, optimizer,
archivist, pentester, writer, heavy, context-updater, extractor — with no personality attached (`roles/`);
`flavors/` (empty by design: voice only, never tools or authority); `playbooks/` (build-feature, code-review, debug,
deep-research, quick-recon, security-audit, auto-research, orchestration, gauntlet); and `tools/comms`, the local
message board parallel phases coordinate on.

Install: `openjawz crew install`. The ops-only subagent preamble lives in `ops/subagent-preamble.md`.
Details: `docs/crew.md`, `docs/identity.md`.
